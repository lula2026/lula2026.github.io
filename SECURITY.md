# Segurança

Encontrou uma vulnerabilidade neste site? Reporte de forma **privada** em
[Security → Report a vulnerability](https://github.com/vbfortes85/lula-hub-site/security/advisories/new).
Não abra issue pública.

O site é estático (HTML, CSS e JS próprios, sem servidor, banco de dados, cookies ou rastreadores) e é publicado automaticamente a partir de um repositório privado, depois de passar por validação.
